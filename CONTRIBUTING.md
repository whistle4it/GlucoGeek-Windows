# Contributing

Start with the README for account setup and docs/DEVELOPER.md for building.

For a bug report, include your GlucoGeek version, Windows version, selected
provider and the visible error text. Use demo data for screenshots. Never attach
settings.json, passwords, session tokens or personal glucose readings.

For code changes, run ./build.ps1 -Test on Windows and explain what you tested.
GitHub Actions also checks the installer. Live account testing is separate from
the offline fixture tests and should be identified as such.

Contributions are accepted under the MIT licence in LICENSE.
